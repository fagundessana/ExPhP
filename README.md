# 🎮 Descubra e se Divirta — ExPhP

Este repositório contém a resolução de uma lista de exercícios avaliativa desenvolvida na disciplina **Programação Web**, com foco na criação de um sistema interativo de exercícios utilizando **HTML, CSS, JavaScript e PHP**.

O objetivo da atividade é criar um menu interativo onde o usuário escolhe um exercício, preenche os campos necessários e visualiza o resultado — tudo em uma única página.

---

## 🎯 Objetivo da Atividade

- Criar formulários funcionais com envio e processamento via PHP
- Utilizar **JavaScript** para controle dinâmico da interface (mostrar/esconder formulários)
- Utilizar **PHP** para processar os dados e realizar os cálculos de cada exercício
- Aplicar **CSS customizado** para estilização e layout responsivo
- Estruturar a página com tags semânticas corretas

---

## 🧠 Tecnologias Utilizadas

- **HTML5** – estrutura e semântica da página
- **CSS3** – estilização, grid layout e efeitos visuais
- **JavaScript** – controle dinâmico dos formulários via DOM
- **PHP** – processamento dos formulários e lógica dos exercícios

---

## 📝 Exercícios Implementados

| # | Exercício | Descrição |
|---|-----------|-----------|
| 1 | **Tabuada** | Exibe a tabuada de um número informado |
| 2 | **Desconto** | Calcula o preço final com desconto percentual |
| 3 | **Aprovação** | Verifica aprovação com base na média de 4 notas |
| 5 | **Soma ao²** | Calcula a soma dos quadrados de 3 números |
| 6 | **Salário Líquido** | Calcula salário com gratificação e imposto de renda |
| 7 | **Nota Bimestral** | Calcula média e exibe situação (Aprovado/Exame/Retido) |
| 8 | **Qual é o Maior** | Encontra o maior entre 3 números |
| 9 | **Soma dos Ímpares** | Soma os ímpares entre dois valores informados |
| 10 | **É par ou ímpar?** | Informa se o número digitado é par ou ímpar |
| 11 | **Calculadora** | Realiza as 4 operações básicas (+, -, *, /) |

---

---

## ⚙️ Como Funciona

- O usuário clica em um dos botões do menu para escolher o exercício
- O **JavaScript** exibe o formulário correspondente e esconde os demais
- O usuário preenche os campos e clica em **Calcular**
- O **PHP** processa os dados via `POST` e exibe o resultado na mesma página
- Os botões **Limpar** e **Fechar** resetam a interface

## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/ExPhP.git
```

2. Mova a pasta para o diretório do XAMPP:
```
C:\xampp\htdocs\ExPhP\
```

3. Inicie o **Apache** no XAMPP Control Panel

4. Acesse no navegador:
```
http://localhost/ExPhP/index.php
```
